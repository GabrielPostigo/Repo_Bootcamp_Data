# Repo_Bootcamp_Data
Repositorio principal en el que iré subiendo y trabajando todo lo que hagamos en clase durante el Bootcamp de Data Analyst realizado en Arrabal-AID

En este repositorio iré subiendo los cuadernos que hagamos en las clases con Daniela, por lo que dejo por aqui los comandos para iniciar un entorno virtual para que se sepa que he ido teniendo que hacer
```bash
python -m venv .venv
source .venv/bin/activate
```

Con esto tendríamos el entorno instaldo, pero, para hacer que funcione el kernel del venv en el cuaderno necesitaremos la libreria `ipykernel`, que se instalará mediante `pip`:
```bash
python -m pip install ipykernel
```
